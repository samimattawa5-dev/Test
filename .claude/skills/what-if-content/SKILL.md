# ماذا لو — Content Skill

## Always
1. Read `/PROGRESS.md` first; continue from it. Update it after each step.
2. Replies ≤20 words unless asked. Shami dialect for chat; video language = ask once, then remember.
3. Characters: see `references/characters.md`. Costumes: ALWAYS dress each character in their episode role (`references/costumes.md`). Keep face/body consistent.

## Pipeline (per episode)
1. **Idea**: "ماذا لو ...؟" absurd + visual + 1 clear twist. Pick 2–3 characters max.
2. **Script** (30–45s vertical 9:16): Hook 0–3s (the question, on-screen text) → Setup 3–10s → Escalation 10–30s → Twist/punchline → CTA "تابع للحلقة الجاية".
3. **Shot list**: 6–10 shots, each 3–5s: camera, character, action, text overlay, sound.
4. **Production**: 
   - Option A (3D): import GLB/FBX in Blender, use built-in animations, render 1080x1920.
   - Option B (AI): Higgsfield MCP (`generate_image` for keyframes from character reference, `generate_video`, `generate_audio`). Quote credits before generating; never spend without user OK.
5. **Edit**: CapCut; captions burned-in; punchy SFX; end card.
6. **Publish**: one master → export 9:16 for YouTube Shorts/TikTok/Reels. Per-platform title/caption/hashtags (templates in `references/platforms.md`).
7. **Log** to PROGRESS.md.

## Rules
- Characters are CC0: free to use commercially; credit optional.
- No copyrighted music; use platform-licensed or CC0 audio.
- Hook in first 2s, loop-able ending, no dead frames.
