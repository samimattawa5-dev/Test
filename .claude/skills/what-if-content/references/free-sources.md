# Free sources (searched 2026-11-15; verify license on each download page)
## Characters (CC0)
- Kenney "Blocky Characters" — likely the user's pack (CC0, rigged, FBX/OBJ/glTF): kenney.nl/assets/blocky-characters
- KayKit Adventurers (CC0, rigged+animated, accessories): kaylousberg.itch.io/kaykit-adventurers
- Quaternius Ultimate Animated Characters (CC0): quaternius.com
- Poly Pizza (CC0 filter) for props/outfits
## Audio
- YouTube Audio Library (safest for YouTube; CC-BY tracks need credit)
- Freesound (filter CC0 only; avoid CC-BY-NC), Kenney audio (CC0), OpenGameArt (CC0 filter)
- Pixabay: check each track (post-2019 = own license)
- Generate own SFX/music with Python (zero risk)
## Voice
- Kokoro TTS (Apache-2.0) ✅ in use. Avoid XTTS/F5-TTS/Piper voices (non-commercial/per-voice limits) unless model card allows.
## Editing
- DaVinci Resolve free, Kdenlive, Shotcut (no watermark); CapCut free (1080p, good vertical). FFmpeg in pipeline.
## Note
Sandbox blocks kenney.nl/quaternius/opengameart/itch.io → user downloads pack and uploads it, or we build blocky characters in Blender.
