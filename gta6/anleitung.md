# Anleitung: Videos für die WoW-Forever-[GERMANY]-Kampagne (NexaClips)

## A) Video erstellen (Regeln)
- Quelle NUR offizielles Blizzard-Material aus dem Content-Ordner (https://f.io/dXkFXJME, Extra https://f.io/8uBzkEqf), DE oder EN
- Format 1080×1920 (9:16), 15–35 s (min. 10 s), ein zusammenhängendes Stück (nur zusammenschneiden, wenn nötig)
- Hook in den ersten 2 s (kurzer wahrer Text, keine Übertreibung), am Ende eine Frage
- Original-Ton klar hörbar, Musik darf ihn nicht übertönen, KEINE KI-Stimmen
- „ist da/erschienen“, nie „bald/Vorbestellen“; keine erfundenen Fakten; nichts „Gameplay“ nennen, was keins ist
- Sprecher zu schnell → 90 % Tempo
- Keine anstößigen/kontroversen Inhalte, nichts Negatives über Blizzard

## B) Caption (alle Plattformen)
Zeile 1: kurzer deutscher Text + Frage (TikTok: + @blizzard_de, YouTube: + @WorldofWarcraftDE, Instagram: kein Tag)
Zeile 2: `#werbung #blizzardpartner` (genau diese Reihenfolge, eigene Zeile)
Zeile 3: max. 3 Hashtags (#worldofwarcraft #wowforever #gaming)
Kein Emoji direkt hinter #blizzardpartner.

## C) TikTok (Nutzer, manuell)
+ → Hochladen → Video → Weiter → Weiter → Beschreibung einfügen → Emoji hinter #blizzardpartner löschen → Inhaltsoffenlegung EIN → Markeninhalt → Markenpartner „Blizzard Entertainment“ → Sichtbarkeit „Alle“ → Veröffentlichen → Profil → Video → Teilen → Link kopieren

## D) YouTube Shorts (Claude postet; manuell falls nötig)
YouTube-App → + → Video hochladen (hochkant, <3 Min.) → Titel mit #Shorts → Beschreibung (Caption mit @WorldofWarcraftDE) → Sichtbarkeit Öffentlich → Veröffentlichen → Teilen → Link kopieren

## E) Instagram Reels (Claude postet; manuell falls nötig)
Instagram-App (Konto nexaclips.hq) → + → Reel → Video → Weiter → Caption ohne @-Tag → „Auch im Feed teilen“ an → Teilen → Reel → ⋯ → Link kopieren

## F) Content Rewards
Kampagne WoW Forever [GERMANY] → „Clip einreichen“ → Link einfügen → Plattform wählen → absenden. Alle 3 Links je Clip. Konten sind verknüpft.

## G) Vorher/nachher prüfen
Vorher: Datei richtig? Caption korrekt? Likes sichtbar? Sichtbarkeit öffentlich?
Nachher: Link gespeichert + eingereicht, 30 Tage nicht löschen, Aufrufe nach 24 h prüfen.
