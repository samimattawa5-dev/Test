# Plattform-Unterschiede (Recherche 22.11.2026, überwiegend Anbieter-Blogs → Richtwerte)

Grundsatz (Nutzer): jede Plattform bekommt eigene Version/Text, kein 1:1-Cross-Post; zeitlich versetzt.

| | TikTok | Instagram Reels | YouTube Shorts |
|---|---|---|---|
| Länge | 21–34 s gut | 15–30 s, Ausnahmen bis ~45 | bis 3 Min., 20–35 s gut |
| Text/Safe-Zone | Text zwischen ~y=290 und y=1250 (1080×1920), unten/rechts UI | oben ~14 %, unten ~20–35 % frei lassen | wie IG |
| Caption | kurz + Frage, 3–5 Hashtags, @blizzard_de | keyword-lastig, 1–5 Hashtags, kein Tag, IG liest Text im Video | Titel 20–40 Zeichen mit Keyword + #Shorts; Beschreibung: Keyword zuerst, <200 Zeichen |
| Cover | – | Cover/Thumb-Frame wählen (thumb_offset) | Titel wichtiger als Cover |
| Hook | Frage/Spannung | Ergebnis/Neuheit | Neugier („Kennst du…?“) |
| Posten | Nutzer manuell, 18:30 | Claude, ~45 Min später | Claude, 18:28 |
| Extras | Inhaltsoffenlegung + Markenpartner | – | – |

Dateinamen: *_tt.mp4 (TikTok), *_ig.mp4 (Instagram), *_yt.mp4 (YouTube); eigene Hook-Texte je Plattform.
Safe-Zone-Layout ab 22.11.: Bild 1080×1080 bei y=480, Hook y=290/385, Endfrage y=1160.
