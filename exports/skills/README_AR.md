# مهارات الموشن جرافيك والترجمة (كل وحدة بملف لحالها)

كيف تستعملها بمشروع تاني:
1. فك ضغط الملف.
2. حط المجلد جوا `.claude/skills/` بالمشروع الجديد. مثلاً: `.claude/skills/caption-animation/`
3. افتح Claude Code بهالمشروع، وبتطلع المهارة لحالها، أو اكتب `/اسم-المهارة`.

ملاحظة: `clip-compositor` و`style-presets` و`word-visuals` و`title-sequence-3d` مبنيين لأدوات `3d-story-shorts`، فبيشتغلوا أحسن إذا نسخت معهم `3d-story-shorts`.
